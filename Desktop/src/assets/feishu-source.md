# Feishu Icon

The unmodified `feishu.svg` is the official icon referenced by
https://open.feishu.cn/ on 2026-11-04.

Source: https://lf-package-cn.feishucdn.com/obj/feishu-static/lark/open/website/favicon-logo.svg

The mark remains owned by its respective trademark holder. It is bundled locally
only to identify the Feishu channel. Loading the icon makes no network request.
