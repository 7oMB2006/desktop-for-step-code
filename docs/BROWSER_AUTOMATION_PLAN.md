# 内置浏览器自动化：现有标签接管

本页记录内置浏览器的授权、资料与生命周期；界面组件和交互样式由 [`DESIGN.md`](../DESIGN.md) 管理。

## 两种目标

- **给网址就打开。** Agent 新开的公网标签保留当前的匿名隔离默认，不自动使用用户的浏览器资料。
- **给标签就接手。** 已加载的 HTTP 和 HTTPS 网页均可分享。用户指明现有标签后，Agent 操作原页面，不按 URL 搜索、重开或刷新。无论最初由谁打开，都保留原页的登录、滚动位置和未保存编辑。能操作这页不等于能枚举其他标签、导出凭据或把原页的浏览器资料用于新标签。空白页和本地文件预览不属于可分享网页。

## 接管和释放

用户在内置浏览器工具栏显式选择「仅查看」或「填写表单」。普通权限只共享给下一条直接发送的普通桌面消息；完全访问下共享可跨轮复用，仍只供该会话直接发送的普通桌面消息使用。完全访问不会自动共享标签，也不会提升已创建的单轮共享。每轮结束都断开连接，后续需要该页时再接手；无关任务仍可按原规则新开页面。

Desktop 主进程把授权绑定到会话、标签及当前文档；持续共享还绑定当前运行时。`desktop_playwright attach` 连接原 WebContents，不接受 URL 或其他目标参数。切换选中的标签不转移权限。导航、关闭目标、用户取消共享或停止接管会撤销授权；退出完全访问或运行时结束也会撤销持续共享。授权不跨应用重启；相同 URL 也不构成替代目标。用户停止接管不关闭原页。

「仅查看」开放页面快照和截图；「填写表单」额外允许填当前主页面的普通文本字段。不开放点击、按键、导航、任意脚本、Cookie 读取或宿主文件上传。填值可能触发网站自己的输入事件；工具不发出提交操作，最终提交由用户决定。

## 浏览器资料和公网

- 「我的浏览器」沿用原有持久分区；「Agent 专用」使用独立持久分区。用户在对应资料中打开网站并自己登录。设置不预装站点，只依据成功导航记录和实际 Cookie 范围列出站点数据。保留以可注册域名为单位的数据管理；有导航记录时显示实际打开过的主机名，重新打开时使用已记录且符合资料浏览规则的来源，不把父域名当作访问过的页面。没有导航记录的 Cookie 范围只显示为数据项。清除前明确提示范围，不读取或展示 Cookie 值，也不导入系统浏览器资料。
- 站点预设按可注册站点匹配，只影响新开的 Agent 标签。不匹配时使用临时匿名分区；命中「Agent 专用」时使用该分区，仅开放查看。Agent 新开的公网网页不自动展开面板、不抢前台。
- Agent 主动新开的公网网页要求标准端口的 HTTPS，此限制不适用于用户共享现有标签。网络代理将主动浏览请求限制在公网地址，跨站文档受限；匿名和预设模式均限制为 GET/HEAD。预设模式下跨站资源请求不会附带 Cookie 或 Authorization，也不接受该响应设置 Cookie。网站兼容性不等同于完整的系统浏览器。
- 本地预览走独立的测试策略。用户主动选择系统浏览器不授予 Agent 操作权，也不是失败后的自动回退。
- 完全访问只会免确认连接当前运行时在本轮启动的本机监听服务。Windows 验证作业对象归属和启动时间；macOS 验证监听 PID 的进程祖先，并按系统提供的微秒级启动时间比较。无法确认归属时仍请求确认。
