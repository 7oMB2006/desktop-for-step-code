# 插件、MCP 与 Skills 管理

## 对齐来源

本轮映射上游 MVP 的管理能力，不建设 DFSC 独立插件生态或社区投稿平台：

- Desktop MVP：`feat/stepcode-desktop-mvp`，本次参考提交 `c052f0b38d01beed38bc22ddb73bcbadf34dc14a`。
- Web MVP：`feat/stepcode-web-mvp-gh`，本次参考提交 `c5a918fdf1936aa1fb2059a330649b61b4c30d00`。
- 两个参考提交的 `apps/web/src/settings.ts` 管理实现相同；复用其用户级范围、市场来源、插件目录身份、MCP 覆盖及 Skill 设置规则。
- 运行逻辑继续由固定版本 Step Code 所有。桌面补丁仅导出其已有插件管理 API，不修改插件格式、执行器或权限规则。

## 入口与范围

设置页分别提供插件、MCP 和 Skills：

左栏共用 `SidebarTaskActions`：上排为等宽的新建会话与插件按钮，下排右侧并排放置
定时任务与搜索图标，悬停显示名称。插件直接打开设置中的插件发现页。搜索按钮固定在右端，点击后以三次方缓动
向左展开，只替换当前导航行，不推移会话列表；Escape 收起并归还焦点。
搜索框目前是明确标注待接入的只读交互占位，不实施会话过滤；支持减少动态效果设置。

- 插件分为已安装、发现、市场来源。支持安装、卸载、添加来源、更新和移除来源；市场来源沿用上游的本地目录、Git URL 和 `owner/repo`。移除来源不卸载已安装插件，更新来源不自动更新已安装插件。
- MCP 区分独立配置和插件声明。独立配置沿用现有编辑器；插件配置不允许单独改写或删除，启停使用上游同名覆盖规则。配置启停与当前会话连接状态分别展示。
- Skills 支持创建、从用户选择的本地文件夹导入、删除及启停。插件提供的 Skill 随所属插件管理，不开放独立删除或开关。
- `/plugin`、`/plugin browse`、`/plugin marketplace`、`/mcp` 和 `/skills` 可进入相应设置。安装、移除等命令只定位待确认的管理页面，不因发送一条命令而直接安装或删除。

管理范围只有 Desktop 独立的用户级目录；不读取个人 CLI 的默认 HOME，不管理项目级资源，也不向个人 CLI 配置写回。会话自身的项目发现仍由原生运行时决定，设置列表不冒充当前会话的全部能力清单。

## 插件图标（DFSC Beta）

图标是本项目的展示扩展，不是 Step Code 上游标准，不改变插件加载、权限或执行规则。
插件作者可在自己的 `step.plugin.json` 中声明 `"icon": "logo.png"`，文件路径相对插件根目录；
本轮不支持仅在市场条目中声明图标。发现页和已安装页使用同一份插件清单。

目前只接收 PNG，单张不超过 128 KiB，宽高各不超过 512 像素，推荐正方形 256×256。
主进程管理 worker 拒绝 URL、绝对路径、越界及链接路径，只返回受限的 PNG data URL；
每次目录查询的图片读取总量限制为 2 MiB。文件缺失、不合规、超出预算或浏览器解码失败时
回退通用插件图标，不影响插件本身。插件无需图标也能安装和运行。

内置市场插件，以及清单与内置副本一致的已安装插件，在没有自带图标时复用账户页的阶跃
标志作为占位。这只是展示占位，不代表发布者认证、签名或完整性验证；
仅使用相同插件 ID 的第三方清单不会因此获得此占位。

## 生效与保护

配置保存和运行时应用分开。更改不会自动重启或热重载现有会话；新会话或用户明确重启后应用。全局运行中任务、审批、队列和设置操作继续受主进程保护。只改管理配置不停止待命 Cron 宿主；手动重启仍遵守 Cron 保护，不能绕过它销毁任务。

卸载前检查所有常驻会话。插件所属 MCP 尚未停用，或无法确认会话已经释放时，不开始删除文件；用户需先停用服务并重启相关会话。尤其在 Windows，MCP 进程的当前工作目录可能占用插件目录，不能先删一部分文件再把目录占用误报成卸载成功。

Electron 主进程持有配置和文件操作权，渲染进程只使用窄化的 typed preload。短期管理 worker 复用上游 API，在独立 HOME 中运行，不接收桌面模型登录凭据；错误、警告和展示数据经过限长与脱敏。插件安装不自动执行上游的额外 provision 下载；Windows StepPage 仍使用原有显式校验准备流程。

开关只改启用状态，保留已有密钥、工具白名单、HTTP 头和超时。插件 MCP 重新启用时清除停用覆盖，不生成空配置。导入不覆盖同名资源；管理操作拒绝越界路径和目录链接。配置中的 MCP 密钥仍沿用现有存储边界，不将此功能描述为配置文件加密。

## 验证

`Desktop/tests/capabilities.test.ts` 通过真正的隔离管理 worker 调用固定运行时，覆盖本地与 Git 市场、更新、插件安装/卸载、MCP 覆盖和敏感字段保留、Skill 创建/启停/导入/删除、无效输入与链接路径。

`Desktop/scripts/verify-capabilities.mjs` 在隔离 Electron profile 中操作真实设置页，验证市场与 Skill 操作、插件声明只读、配置与连接状态分离、显式重启后的实际 Skill 命令和 MCP 连接变化，以及主题与窄窗口。它使用本地确定性 MCP 服务，不调用付费模型、登录、发布网页或修改个人 profile。

前端示例：`Desktop/tests/fixtures/capability-settings.html`。示例使用模拟数据；安装与真实运行时验收以上述 Electron 脚本为准。打包、真实第三方服务、首次安装和云端 CI 仍需分别验收。
