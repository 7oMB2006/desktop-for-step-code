# DFSC 通用外部委托接入计划

日期：2026-11-10

## 目标与边界

让普通 DFSC 提供一个受支持、默认关闭的本机外部委托接口。宿主负责
连接身份、目录授权、原生会话、消息队列、人工审批及生命周期；
Hermes companion 是首个独立适配，不把 Hermes、飞书或其他机器人逻辑内置。

本轮不实现 QQ、微信、OpenClaw、公网服务、无人值守审批、预算托管、
旧 Hermes 专版的全部工程协议、自动安装模型、插件代码执行或市场发布。
不推送、合并、发版，不修改用户真实配置，不重启用户应用。
已有未提交的插件引导和资源改动原样保留。

## 协议与权限

传输采用只监听 `127.0.0.1` 的有界 JSONL 请求/响应，名称为
`dfsc-external-v1`，配置、描述符、请求及能力响应均携带显式协议名。
不提供 HTTP、浏览器 CORS 或任意 Desktop IPC。
每连接使用独立随机 bearer token；身份由宿主凭据确定，不相信请求中的
agentId、source=human、origin 或任意授权声明。

在“远程访问”中加入“外部 Agent”管理区域：

1. 人工打开本机接入开关，宿主才监听端口。
2. 人工填写连接名称，从已知项目选择授权目录，确认后创建连接。
3. 宿主生成私有 `agents/<id>/model.json` 和不含 token 的
   `agents/<id>/config.json`。界面只展示连接配置文件路径，可复制给适配器。
4. Hermes 安装工具显式导入该配置到指定独立 profile，备份已有配置；
   不自动覆盖旧模式、不读取人类凭据、不重载 gateway。
5. 人工可以逐连接撤销或关闭整个入口。撤销后拒绝新请求，撤回仍可撤回的
   原生队列输入，不自动终止已经开始的原生工作；本机仍能停止和查看会话。

配置保存在当前 Electron userData，绝不回退到个人 Step Code 配置。
描述符中的 bearer token 是当前用户目录内的明文凭据；文件 mode 不代表
已经验证 Windows ACL，也不防御同一用户身份下的恶意进程。
新界面不展示或复制 token。拒绝符号链接替换、非规范目录、UNC 等显式网络路径、
未知项目、越权子目录及失效目录。第一版只允许选中的项目根目录本身，
不把对根目录的授权解释为任意绝对路径读写能力。授权记录同时保存规范路径
和目录 dev/ino，创建及派工时重验，目录同名重建也需重新授权。
不保证识别 Windows 映射网络盘；目录身份不是内容完整性保证。
本机 loopback 假定可信单用户环境，不是跨 OS 用户的安全通道。客户端未验证
服务端身份，凭据跨重启保留，不防御不可信用户抢占陈旧端口后窃取凭据。

支持的方法：

- `system.capabilities`：明确返回协议名、身份、授权根目录和实际支持的方法。
- `task.create {key,cwd,title}`：幂等创建专属原生 Ask 会话，不占用当前草稿，
  不附着或读取已有本地/飞书会话。
- `run.submit {taskId,key,message}`：一次任务只接收一轮派工，通过现有队列。
  重复相同 key/内容返回原结果，key 内容冲突拒绝；超时不得盲目重放。
- `task.list`、`task.get {taskId}`：仅自身任务的有界状态；只有 get 返回已捕获的回答摘要。
  不导出思考链、原始环境、凭据、完整工具输出或不相关历史。
- `task.stop {taskId}`：仅自身任务，先撤回未发输入，否则走原生停止路径。
  只停止仍确认属于本次外部提交的轮次，不影响之后在本机开始的新工作。

不开放 `approval.respond`、`human.*`、任意命令、权限切换、自动恢复或续跑。
遇到审批/问题，查询结果显示需本机处理；外部 Agent 不能代替真人批准。
项目授权是路由权限，不是操作系统文件沙箱；原生 Ask/信任仍独立生效。
原生任务结束不等于测试通过，也不等于用户已验收。配对授权的是该进程的
任务发起能力，不核验之后输入来自真人，不继承旧版逐条飞书消息核验。

## 生命周期与可靠性

保存连接和有界任务元数据，不保存提示词/回答/令牌到普通状态投影。
任务创建/派工意图应先记录再产生原生副作用；失败结果不确定时标记未知，
不通过重试创建第二份任务。重启恢复连接配置，不重放旧消息、任务或审批；
未完成任务标记中断，历史仍保存在原生会话。

每个任务独占会话；关联存在时不能被空会话复用。异步步骤在创建、排队前
重新核对连接是否仍有效、目录是否仍授权。撤销、关闭及退出先使授权失效，
再关闭连接；等待在途管理操作收束，不遗留监听或子进程。
独立保留集合接入 runtime retain，不复用飞书的 remoteAttached 位。
每次提交核对同一个 worker/rpc/session/cwd 及 Ask 策略，并拒绝前导 slash
控制命令。只有本次派工终态事件可以捕获回答摘要，终态后冻结，不能随查询
读取后续人工对话。撤销写盘失败时关闭入口并报错，不声称持久撤销成功。
