# MCP 账户凭据默认隔离

本轮是插件宿主能力计划 [Ⅰ] 的隔离候选，不是通用授权桥的交付或发行公告。
固定 runtime pin 仍为 `29eb460780489801ce8afc8bffc1a2efae7cbded`；
不修改独立维护的 Step-Code 工作区，也不改变原版 Step Code CLI 的行为。

## 本轮策略

Desktop 的 MCP stdio 环境只包含：

1. MCP SDK 默认允许继承的基础变量。
2. 该服务明确声明的 `env`，包括用户有意配置的独立 Key。

不再从 Step 登录存储读取 OAuth access token 或 API Key，补到
`STEPFUN_API_KEY`。未声明、空值、空白及声明了其他名称的情况都不能触发账户兜底。
诊断使用同一解析器；缺少独立配置时不能提示“登录即可使用”。

这是 Desktop 固定 pin 的适配补丁，不依赖作者填写占位符或选择特定变量名。
旧的 `DFSC_INDEPENDENT_PLUGIN` 声明仍按普通显式字符串传递，保留旧包兼容，
但不作为本轮隔离的实现依据。不会清空用户明确保存的独立 Key，
也不会更改账户、插件设置或计费渠道。

补丁、原始源文件、修改后源文件均在 `patches/v017/manifest.json` 锁定。
staging 验证全部后像后重新构建，并声明
`desktop-mcp-credential-isolation`；仅有源码修改或旧 runtime 不算生效。

## 启动路径

| 路径 | 策略与边界 |
| --- | --- |
| 主进程到 Step RPC | 保留现有 Desktop 私有账户通道，运行时消费后删除环境载荷；主会话仍需使用账户 |
| 已安装插件 MCP | 原生发现与连接共用受限环境，不再自动补入 Step 账户 |
| 手工配置的 stdio MCP | 与插件使用同一解析器，不因缺少插件身份恢复兜底 |
| MCP 再启动的普通子进程 | 不会继承父 MCP 未收到的账户凭据；显式独立 Key 仍可由作者有意继承 |
| 子代理中的 MCP | 子代理保留模型执行所需的现有私有账户通道，连接 MCP 时仍经过同一解析器 |
| 内置 StepPage | 不按名称豁免账户隔离；保留已有注册与准备流程，缺少显式配置时不保证部署可用 |
| 插件管理与诊断 worker | 不启动插件业务，只检查同一环境策略；账户登录不再满足 `requiresEnv` |
| 远程 HTTP MCP | 本轮没有修改其独立 OAuth、显式请求头或环境引用协议，不提供 Step 账户代理 |

环境白名单原本已存在。本轮关闭的是之后的登录凭据兜底，
不是新建进程沙箱，也不是对所有宿主变量、外部工具及网络出口的完整审计。
StepPage 的旧准备路径和远程 MCP 的环境引用仍需在后续通用宿主边界中单独审查。
插件与 MCP 是本地原生代码；同一系统用户的主动文件读取、恶意复制或外传独立 Key
不在这项环境隔离保证内。

## 兼容与发布门槛

- 旧进程已经收到的 Key 不能被这项修改收回；只对使用新 runtime 的新启动生效。
  不自动停止日用应用、会话或定时任务。
- 依赖 Step 登录自动获得 Key 的服务需要显式独立配置，或等待受控宿主授权入口。
  不静默重新注入，不自动切到独立 API 计费，也不改写用户配置。
- BVR 的已有专用账户桥保持不变；独立 Key、配置、Plan/API 路由与拒绝逻辑继续回归。
  本轮不等于 BVR 已迁移到通用授权，旧全局连接凭据的退场另行验收。
- 暂不把本轮作为单独的破坏性升级发布。组合发行前必须完成计划 [Ⅲ][Ⅳ] 的
  通用入口、BVR 迁移、最低兼容版本及可操作的升级提示。
- 首次安装风险确认、作者 SDK 打包示例、通用配置与授权界面不在本轮实现内。
  市场风险文档已经合并，不代表上述客户端交互已经完成。

## 验收方式

`Desktop/tests/mcp-credentials-runtime.test.ts` 使用一次性目录、假 OAuth/API Key、
真实固定 pin RPC 与 MCP 握手，读取仅含布尔结果的父进程/后代检查记录，
不输出原始环境。覆盖无占位符、错误名称占位符、旧占位符、显式独立 Key、
手工服务、仿内置服务名及真实管理 worker 诊断。
启动阶段不发模型请求；假凭据、私有会话能力和账户载荷不得进入事件与摘要。

未修改 runtime 必须在同一用例中被检测出自动注入；候选 runtime 必须通过。
补丁重放、Desktop 类型检查/构建、协议回归、Electron、云 CI、原生 macOS、
安装器及真实账户是不同验收层次，具体结果见 `docs/VERIFICATION.md`。
测试不能证明真实 TTS、计费或恶意代码沙箱已经可用。
