# 插件风险确认接口 v1

## 范围

插件在 `dfsc.plugin.json` 顶层声明 `confirmations`，宿主在实际执行相应动作前，
使用主窗口所属的原生警告对话框展示插件身份、插件风险和宿主计算的实际授权范围。
它不是 HTML/脚本扩展点，不授予插件 Node、文件访问、任意 RPC 或全局拦截权限。
现有顶栏状态二级面板和只读工作台不变。

首版只支持 `external.delegate`（委托现有任务审批）和
`external.policy`（设置或修改长期策略）。不拦截查看状态、普通派工、停止、
撤销、关闭接入或不相关插件的动作。后续动作必须在宿主增加执行点，
不能靠插件自定义动作名、条件表达式或脚本启用。

## 声明

```json
{
  "schemaVersion": 1,
  "confirmations": [{
    "id": "persistent-delegation",
    "version": "1",
    "action": "external.policy",
    "policy": "remember",
    "title": "长期执行授权",
    "message": "授权跨任务和重启保留，模型可能误判，目录不是沙箱。",
    "confirmLabel": "知晓风险，继续授权"
  }]
}
```

- 最多 8 项，ID 和动作各自唯一。`action` 仅支持上述两个固定值。
- `policy` 为 `always` 或 `remember`。后者仍由用户自行勾选，默认不记住。
- `version` 为 1–64 个字母、数字、点、下划线或连字符。
- 标题、正文、确认按钮最长分别 160、1600、40 字符；纯文本，不允许控制字符或方向控制符。
- 风险文案可自定义；插件身份、实际 Agent、工程、档位、期限、审批类别由宿主提供，
  取消和默认焦点也由宿主控制，不能用插件按钮文案替换。

## 关联与身份

在「远程访问 → 接入渠道 → 外部 Agent」配对时明确选择关联插件，
或为没有进行中任务和长期策略的旧普通连接点击「关联插件」并确认。
宿主只接受已安装、有可验证安装记录且声明有效的插件。不能由连接名称、
模型参数、任务内容、环境变量或插件自行宣称建立关联。

关联保存稳定的安装身份，不保存瞬态 renderer ref。更新后可读取同一安装的新声明，
卸载重装、来源变化、安装记录不再匹配或声明不可读时，新的相关授权失败，
不能降级成“插件没有风险”。不提供解除或替换关联的快捷入口，
需先撤销连接再重新配对。旧普通连接保持原行为，不自动关联 Hermes。

## 确认与权限

确认只是知情记录，不代替授权，不开启接入、不增添目录，也不修改权限档位。
宿主在 main 的授权动作入口检查，绕过表单直接调用同一 IPC 仍须确认；
模型协议和独立插件窗口没有回答风险确认或修改通用授权的接口。

取消、关闭窗口、插件变化、凭据/目录失效或确认期间撤销均不执行授权动作。
已有策略不因取消修改而丢失。停止和撤销不被确认框拦截；
确认中发生撤销，迟到的肯定回答不能恢复权限。

记住的范围包含安装身份、包指纹、风险完整内容与版本、凭据和规范目录身份，
以及本次动作的 Agent、项目、期限、档位、类型；任务委托还绑定任务 ID。
存储只保留哈希，最多 256 项，在 Desktop 自有目录持久化。
变化时重新确认；“always”从不复用。记住不会自动同意新的权限请求，
撤销授权也不等于清除已知晓记录。不承诺追溯撤回已经生效的授权或操作。

原有 Ask、项目信任、委托范围校验、审批记录和原生自动执行策略仍独立生效。
项目根目录不是操作系统沙箱；撤销不能还原数据，也不保证终止所有已派生进程。

## 兼容

`system.capabilities` 返回 `pluginConfirmations: { version: 1, pluginId?: string }`，
其中插件 ID 来自宿主保存的关联，不来自网络请求。
只表示此宿主实现接口和连接的关联，不表示用户已确认风险或授权执行。

不能只凭 DFSC 数字版本判断支持。声明依赖确认能力的 companion 应检查接口版本
和自己的插件 ID，在不支持时阻止相应新操作并提示升级或关联，保留查询和停止。
旧宿主可能忽略未知 metadata 字段，因此不能把声明本身当作兼容性保护。

## 验证边界

单元测试覆盖取消、确认范围、持久化、始终提示、撤销竞态、包变化、
重装、失效声明、坏存储、并发、无关动作及身份校验。
浏览器夹具验证关联控件的窄屏、明暗主题和四边 focus。
Electron 验证使用隔离 profile、真实 main/preload/本机协议和受控原生对话框响应，
不代表用户真实点击、真实 Hermes 模型、飞书、过夜或安装包发布验收。
