# Desktop 全文搜索

## 入口与读取

左栏原有搜索仍即时匹配标题、首条消息、项目名及目录，保留原分组、
顺序、折叠偏好和草稿。其下的“搜索聊天记录”打开正文检索页，可按项目、
时间和是否包含归档筛选。结果按会话分组，首次显示 30 条，可继续显示本批结果。

点击片段先读取只读历史，不选择会话、不启动会话运行时、不写回 JSONL。
可见消息具有相同 `entryId` 时滚动、聚焦并高亮；返回恢复结果位置与焦点。
标题命中、降级结果没有消息定位；不在当前分支或已压缩的命中也会明确提示，
显示当前可读上下文，不拼接废弃分支或恢复旧内容。“打开并定位”才走原有
会话恢复流程，并将命中的 `entryId` 和关键词带入正式会话；长消息优先滚动到
关键词所在行，而不是整条消息的中点。正式会话顶部保留“返回搜索结果”与
“重新定位”，前者保留关键词、筛选、结果位置及焦点，后者不重建运行时。
定位只在显式打开或重定位时滚动，普通快照刷新不抢焦点或拉回底部。正式会话
已不包含命中消息时明确提示，不借用相同数组下标或重放废弃分支；会话级降级
仍显示“打开此会话”，不提供虚假的消息定位。切换其他会话或关闭定位栏清理
高亮，导航失败保留搜索预览和查询。搜索期间暂时隐藏原会话工具面板，
不终止浏览器、终端或后台任务；待审批操作保留返回处理的提醒。

## 数据边界

- Electron 主进程经 typed preload IPC 调用已有管理进程，后者懒加载上游
  `openSessionIndex` / `createSessionSearchService`；不另造数据库访问层。
- 仅注册 Desktop 数据根目录的 `sessions/`，包括其中的导入记录。配置目录
  `agent/` 与会话目录并列；索引位于 `agent/index/desktop-session-search.v1.db`。
  未创建会话的草稿也能检索；不采用个人 CLI 默认目录。
- JSONL 仍为权威数据，索引为可重建派生数据。沿用上游查询时增量刷新，
  返回前再核验已知会话身份、文件存在性与实际路径归属，排除删除或越界文件。
- 默认排除归档；项目使用 Desktop 当前归属，包括会话迁移后的项目。
  子代理会话维持上游排除规则，Desktop 也复核保留命名空间。
- 上游索引包含用户／助手文本、压缩与分支摘要、显式展示的自定义消息及标签，
  单条索引正文最多 64 Ki 字符。不包含工具结果、bash 输出、扩展私有记录
  或图片／附件文件内容；不是磁盘文件内容搜索。
- 只向 renderer 返回消息标识、文本片段及必要状态，不返回数据库或命中文件路径。
  片段标记作为 React 文本解析，不注入 HTML；预览高亮使用 DOM Range。

## 覆盖范围

普通查询最多返回 100 条。含任意不足 3 个字符的关键词时，上游仍会检索正文，
但只在时间范围内最近 200 个会话中检索、最多返回 50 条；未选时间时默认近
30 天。短查询不是“只搜标题”。

上游当前没有搜索游标或 Desktop 归档／迁移归属过滤参数。项目与归档过滤作用于
这批有界结果，不是过滤后重新补足 100／50 条。达到上限时界面明确提示收窄关键词，
本地“加载更多”仅继续显示本批结果，不宣称全库分页或精确总数。

索引建立期间显示覆盖进度并自动重查，保留已有结果且不抢走焦点。部分索引失败、
短查询限制和达到上限分别提示；部分覆盖的空结果不称作全库无结果。上游 SQLite
不可用时沿用 JSONL 降级查询，显示会话级匹配，不承诺具体消息位置。

输入去抖后查询。关键词／筛选变化、关闭或退出时取消旧请求，并按请求身份拒绝
过期响应；旧取消不能影响新查询。取消不承诺物理中断已在 SQLite worker 中
执行的同步语句。查询失败保留关键词和筛选，允许显式重试。

## 验证入口

- `Desktop/tests/fulltext-search.test.ts`：参数和路径边界、投影、取消、真实 SQLite
  worker、导入记录、追加／删除、私有根排除，以及真实数据库失败后的 JSONL 降级。
- `Desktop/scripts/verify-fulltext-search.mjs`：隔离 Desktop profile 的实际 Electron
  IPC 检索、只读定位、草稿／运行时／JSONL 不变、归档／项目／时间筛选、焦点恢复、
  浏览器隐藏与中英文／亮暗／窄窗口。失败、部分覆盖和乱序等 UI 状态使用故障注入，
  不冒充实际索引服务的对应故障。
- `Desktop/tests/fixtures/fulltext-search-native.html`：复用正式组件的示例数据预览，
  无个人记录、账户或模型访问。旧 `fulltext-search.html` 仍是原交互方案，不是运行时验收。

新增验收已注册 Windows 与 macOS 共享 CI 清单。Windows 包内验收与用户本机体验
已通过；云端 CI 与原生 macOS 结果仍需分别验收，本地 Windows 通过不替代它们。
