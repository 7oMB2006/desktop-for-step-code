# Usage [Ⅱ]：本会话消耗估算

## 范围与展示

- 上下文右栏随已经生效的官方账户显示 Plan 的 M Credit 或 API 的金额，不提供改变真实计费方式的展示开关。
- 估算仅覆盖桌面主会话收到的模型响应，不含搜索、并行子代理及上下文维护调用；不是账户余额、完整任务成本或官方账单。
- 第三方供应商只保留 Token 统计，费用显示 `--`。未来手动配置第三方价格属于 Usage [Ⅳ]，P2，暂不排期。
- 海外 Plan 的 Credit 换算尚未核实，显示不可估算；未知模型、路由模型及无有效用量的响应不伪装为免费。
- 历史会话没有请求身份和规则快照，不按当前账户补算。已有账本不随上下文压缩丢失。
- 估算标题旁使用圆圈感叹号入口，悬停或键盘聚焦复用现有 Tooltip 与入场动画，展示估算范围、规则及当前账户的历史分组，不增加常驻展开行。

## 身份与持久化

- 主进程在运行时启动时绑定已生效凭据，在 `message_start` 冻结账户、地区、模式、规则与开始时间，`message_end` 记入账本。
- 手动资格仅影响后续响应的本地估算，不重算已记账响应，不修改登录、路由或官方扣费。
- 优先使用官方数字 UID 生成不可逆账户标识；无 UID 的 API Key 按凭据隔离。更换 Key 可能被视为另一账户，不擅自合并。
- 账本位于 Desktop `userData/usage-estimates/`，按会话存储；不写入提示词、原始响应或明文凭据。
- 每条记录保存规则与价格版本及计算结果。重复结束事件不重复累计；切换账户和模式只改变当前展示分组，旧分组保留。
- 本功能不改变既有“Plan 失败不得回退直调 API”的路由保护。
