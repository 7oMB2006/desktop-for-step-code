# Desktop for Step Code v0.1.0：首个 Windows 社区预览版

> 本文件是发布文案草稿，不代表已经发布。版本暂定，已生成本地候选安装器，最终提交与验收尚未冻结；完成 RELEASE.md 的门槛并得到维护者确认后才可用于 GitHub Release。

一个面向 Windows 的 Step Code 社区桌面客户端。你可以使用自己的 Step Plan 账户或 Step Platform API Key，打开本地项目，在桌面界面中完成和继续 Agent 编程任务。

本版定位为社区预览，不是 StepFun 官方产品，也不承诺覆盖所有运行环境。

## 首版带来了什么

- **会话工作区**：项目与独立会话、拟创建页、固定排序和拖动、项目置顶、归档与恢复、永久删除。
- **持续交互**：并发会话、FIFO 排队、主动插队引导、引用回复、会话分支与会话链接。
- **执行反馈**：流式正文、思考及响应耗时、工具审批、子代理状态和摘要板。
- **检查与预览**：上下文检查、会话导航、单轮记录改动、有限撤销、Git 工作目录与分支 Diff。
- **内置工具**：用户操作的 PowerShell 终端、多标签浏览器、Markdown/文本文件预览、网页与交付产物引用、按文件类型记忆打开方式。
- **界面体验**：明暗主题、中英文界面、窄窗适配和减少动态效果。中文新建会话问候已扩充，英文语录会在后续版本补充。

## 安装与开始

仅支持 Windows x64；本版不提供 macOS、Linux 或 WSL 兼容承诺。

1. 下载 Release 附件中的 Windows NSIS 安装器，对照 `SHA256SUMS.txt` 核验文件。
2. 运行安装器，选择安装目录并启动应用。
3. 在账户设置中登录自己的 Step Plan 账户或填写 Step Platform API Key。
4. 选择已有项目、打开本地目录或使用独立会话，选择模型后发送第一条消息。

安装包包含 Electron 和固定 Windows Step Code / Node 运行时，不要求安装 Desktop 的开发依赖。Git/Bash、项目专用工具和 MCP 服务端依赖仍需自行安装。是否具备模型使用资格由你的账户与服务端决定，安装应用不会赠送额度。

当前候选安装器未签名，Windows 可能显示 SmartScreen 或“未知发布者”提示。请核对下载来源与 SHA-256；不建议为了安装而关闭系统安全防护。最终公开附件的签名状态仍需再次核对。

## 数据与操作边界

Desktop 数据存放在 `%APPDATA%\Desktop for Step Code`，不复用个人 Step Code CLI profile。Step 登录凭据按当前 Windows 用户加密存储；这不能防护同一用户身份下运行的其他软件。

正常卸载清除 Desktop Step 凭据，保留会话、设置和工作区文件。MCP 配置中的秘密不属于该凭据清理范围。永久删除会话及撤销文件改动前，请确认操作范围并保留必要备份。

并发会话可能操作同一文件。协作提示和跨会话工具不是文件锁，也不能保证没有冲突。撤销只针对可记录且能安全匹配的改动，不是完整工作目录事务回滚，也不会回滚工具的外部副作用。

## 已知限制

- 浏览器目前面向用户操作，未提供 Agent 浏览器控制或 Playwright MCP 集成。网站登录、OAuth、下载和媒体权限可能受隔离策略及站点兼容性影响，不承诺全部站点可用。
- 终端运行本机命令，不是安全沙箱；关闭标签会终止其所属进程，应用重启不恢复终端进程。
- 单轮 Diff 不能完整归属 Shell 命令或缺少 before-image 的所有文件变化；Git Diff 展示的是仓库状态，不等同于当前 Agent 的专属改动。
- 第三方应用能否打开文件取决于本机安装和文件关联；自动验收拦截了第三方启动，不代表所有编辑器兼容性已被验证。
- 队列草稿不跨应用退出保存；部分执行标记只在当前 worker 生命周期内保留。
- StepPage 在 Windows 上需要已安装的官方 bundle；实际向 StepPage 发布尚未完成验收。
- 自动 fixture 覆盖不等于所有真实账户、模型和 MCP 场景通过。最终候选的真实烟测与安装生命周期结果须在发布前补充。
