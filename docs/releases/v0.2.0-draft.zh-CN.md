# Desktop for Step Code v0.2.0：更新提示、后台托盘与阅读排版

第二个 Windows x64 社区预览版。`0.2.0-rc.1` 已完成本地回归和用户确认的云桌面覆盖升级，最终编号 `0.2.0` 已重新构建并通过本地回归，不表示已正式发布。可直接用于 Release 正文的文案见 [v0.2.0.zh-CN.md](v0.2.0.zh-CN.md)；本页保留候选验收记录。

## 本次更新

### GitHub 新版检查

- 设置中新增独立的“版本更新”页面，支持手动检查、版本说明和官方安装包下载入口。
- 启动后自动检查，此后每六小时复查；可关闭自动检查，或选择仅正式版通道。
- 发现新版时，在左下角设置入口显示更新提示，不打断正在运行的任务。
- 下载由系统浏览器完成，不静默安装，也不会自动重启应用。

### 后台托盘

- 关闭窗口后保留在 Windows 托盘，Agent 任务、队列、终端和浏览器继续运行。
- 从托盘恢复窗口，或使用托盘菜单、文件菜单明确退出应用。
- 托盘菜单沿用软件内的主题和交互样式。

### 字体与阅读排版

- 设置中新增独立的“外观”页面。
- 界面、正文、代码与 Diff 可以分别选择预设字体和字号。
- 正文提供紧凑、标准和宽松三档行距，支持预览与恢复默认。
- 正文默认字号由 14px 调整为 15px；文字调整不连带放大按钮和图标。
- 偏好保存在本机，重新打开应用后继续生效。

### 其他

- 新建会话中文首句修正为“让想法阶跃星辰”，与“星辰因你而阶跃”等概率出现。

## 下载与升级

选择本 Release 的 Windows x64 安装包，并使用随附的 `SHA256SUMS.txt` 核对文件。

升级前请结束运行中的任务，通过“文件 → 退出应用”或托盘菜单退出。仅关闭窗口不会退出本版本。

**v0.1.0 没有新版检查功能，需要手动到 Releases 页面下载此次更新。** 本版本安装后的后续升级，可以使用左下角提示及“版本更新”页面，但仍需自行下载并运行安装包。

应用使用现有 Desktop 配置目录，正常覆盖升级应保留账户、设置与会话。RC 云桌面升级已获用户确认；最终编号安装器未重复安装生命周期测试。不要为了升级先删除个人数据。

## 已知边界

- 仅提供 Windows x64 安装包；其他平台不属于本次发布范围。
- 字体选择目前是预设列表，不是本机全部字体枚举。
- 本版本不包含按小白、普通开发者、深度开发者划分的前端能力模式。
- 更新检查依赖访问 GitHub 公开资源，断网或访问受限可能导致检查失败。
- 当前安装包没有代码签名，Windows SmartScreen 可能提示未知发布者。
- 上游 Step Code runtime 保持现有固定基线，本次不是 runtime 升级。
