# v0.3.0 发布准备与验收

核对日期：2026-10-10。状态：发布范围及正文已整理，已开始准备 `0.3.0-rc.1`，尚未创建 tag 或发布 Release。候选包及验收状态见后续记录。

可用于发布的中文正文见 [v0.3.0.zh-CN.md](v0.3.0.zh-CN.md)。版本规则沿用 [VERSIONING.md](../VERSIONING.md)，历史 feature 证据见 [VERIFICATION.md](../VERIFICATION.md)。

## 发布主线

第一优先级是锚定上游 Step Code 的更新，修复 Subagent 链式结果传递、任务收尾与状态展示；自定义供应商是第二个功能亮点。标题同时体现两者，开场明确固定提交及上游后台进度隐藏、终态与需要输入事件唤醒父代理的变更；更新章节仍以 Subagent 为先，不把本版描述成主要由供应商功能驱动的发布。

上游运行时改进与 Desktop 客户端修复分别说明。候选验收优先验证固定 runtime 的集成、链式结果完整传递、后台终态唤醒父代理，以及成功/失败/中断后的前后端状态一致性；不将“已修复已知问题”外推为所有 Subagent 场景无缺陷。
