# Desktop for Step Code v0.3.0：跟进上游，修复 Subagent 协作，支持自定义供应商

本次 Windows x64 社区预览版锚定上游 Step Code 提交 `f7392089`：纳入后台进度通知不再混入正文，以及子代理终态和需要输入的事件通过 steer 唤醒空闲父代理的改进。在此基础上，修复链式子代理的结果传递、任务收尾及客户端状态展示；同时新增自定义供应商配置、模型发现与连接诊断，并完善会话、模型选择和右栏交互。

> 预备发布正文，尚未发布。安装器和验收完成后再使用，不能用本页代替候选包验收记录。

## 本次更新

### 跟进上游与 Subagent 修复

- 升级固定的 Step Code 运行时，纳入后台进度隐藏和结束事件唤醒父代理等上游改进；桌面客户端随固定基线构建，不在运行时自动追随上游最新代码。
- 修复链式子代理的结果传递与状态收尾，避免将链路中间记录或已结束任务错误显示为继续运行。
- 修复 Workflow 子会话混入左栏的问题，内部子会话不再作为独立会话显示或打开。
- 客户端补齐成功、失败和中断的状态区分：分别使用绿色勾圈、红色叉圈和黄色警示图标，运行及收尾沿用统一动画，并提供二级状态提示。

以上包含上游运行时更新与客户端适配、展示修复，不代表所有多代理场景已无缺陷。

### 自定义供应商

- 设置新增供应商配置，支持 Chat Completions、Responses 和 Anthropic Messages 三种协议格式；可配置 Base URL、API Key、模型及本地无密钥服务。
- 可从接口获取模型列表，选择加入或刷新模型，也可手动填写模型 ID。
- 模型参数展示接口声明的能力与容量信息；思考档位区分接口声明和手动配置。接口没有提供可用思考控制信息时使用服务默认，不自动猜测档位。
- 支持按接口文档配置思考档位及发送值映射。Anthropic effort 需要显式配置 adaptive 支持；本版不提供 budget 型思考控制。
- 新增连接诊断：使用当前配置发送一条短文本请求，显示结果、耗时及可复制的诊断摘要，无需创建会话或先保存供应商。
- 任务运行中也可保存供应商配置；当前任务继续使用已应用的配置，全部任务与队列空闲后自动应用新配置。

### 会话与模型选择

- 优化会话切换的加载反馈和阅读位置恢复，减少重复加载带来的闪烁；切换失败时保留已确认会话。
- 任务运行中可以预选模型与思考档位，下一轮新任务启动前生效。当前任务与插队引导继续使用原配置。
- 实际模型切换后，正文时间线显示“模型已切换”及前后模型名称。该提示由客户端记录，不作为工具调用，也不进入模型上下文。
- 修复 Step Plan 登录后初始化时思考档位不可见，以及内部能力提示意外进入正文的问题。
- 修复有待发送消息、无 Diff 块时，回到底部按钮偏移到左侧的问题。

### 右栏与设置

- 再次点击已打开的产物或网页引用，可原处收回对应右栏。
- 右栏边界新增抓手，按现有尺寸档位切换，不引入自由宽度；保留浏览器和终端等已打开内容的状态。
- 设置统一为固定大小、受窗口边界约束的二级视窗，分类切换不再改变窗口大小。
- 全部应用区域置于模糊背景之下，打开和关闭具有对应动画；关闭动画结束前保持背景不可交互，避免键盘误操作。

## 下载与升级

发布后下载本 Release 附件中的 **Desktop for Step Code Setup 0.3.0.exe**，并使用 `SHA256SUMS.txt` 核对安装器。

升级前结束运行中的任务，使用“文件 → 退出应用”或托盘菜单退出旧版，再运行安装器覆盖安装。仅关闭窗口不会退出应用。不要为了升级删除配置目录或个人数据，重要项目与会话仍建议提前备份。

`v0.2.0` 用户可以通过左下角更新提示及“设置 → 版本更新”发现新版；`v0.1.0` 用户需手动查看 Releases。**更新功能不静默下载安装，也不会自动重启应用。**

## 已知边界

- 本次安装包适用于 Windows x64。
- **自定义供应商当前为 Beta**，采用通用协议接入，不表示所有供应商、代理服务或模型均已验证。接口特有参数和行为仍可能不兼容。后续针对知名供应商的专配目前优先级不高，暂无时间承诺。
- 模型列表与能力信息取决于接口返回值；未声明的项目需要用户确认。显示音频等模态声明不代表客户端已支持对应输入或输出。
- 连接诊断只证明一次短文本请求能正常返回，不代表流式输出、工具调用、图片输入或长任务均已通过。
- 尚未生效的模型预选不会跨应用退出保存。运行中切换不会更改当前任务或插队引导的模型。
- 多代理并发不提供项目文件锁或事务隔离，仍需合理划分修改范围。
- 安装包仍未做代码签名，Windows SmartScreen 可能提示未知发布者。请核对官方仓库来源与安装器哈希。
- 更新检查依赖 GitHub 公开资源；本版建议继续标为 GitHub Pre-release，仅正式版通道不会提示本社区预览版。
