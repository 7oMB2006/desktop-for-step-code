# Desktop for Step Code v0.4.0：跟进 Step Code v0.1.4，完善 Plan 与协作体验

本次 Windows x64 社区预览版锚定上游 Step Code v0.1.4 公告对应的源码基线 `3ba89e0c`，纳入 Ultracode 恢复、默认 CLM 上下文管理及 Windows 命令执行改进。在固定运行时的基础上，桌面端补齐编排观察、Plan 批阅与执行、Goal 状态收尾，以及三档权限的授权交互，让长任务从发起、审批到恢复更连贯。

> 发布正文草稿。首个候选安装器已通过本地包内验收；真实模型烟测及升级验收尚未完成，不代表本版已经发布。

## 本次更新

### 跟进上游与协作恢复

- 更新固定的 Step Code 运行时，并适配 Ultracode 的会话恢复、中断状态与显式续跑。
- 编排进度接入脉冲状态和子代理右栏，可在编排概览与单个子代理之间切换，查看各步骤的状态及结果。
- 收尾后保留对应轮次的编排记录；多条历史记录收纳到有界、可滚动的选择菜单，避免右栏不断堆叠。
- 改进 Windows 原生 Git Bash 发现，支持非默认 Git 安装路径与显式 shellPath；执行失败保留退出状态，后台命令提供日志路径和读回结果。无可用 Bash 或显式路径无效时明确报错，不静默换用其他 shell。

### Plan 与 Goal

- 聊天栏提供 Plan、Goal 与 Ultracode 的启用入口，Plan 与 Goal 互斥，Ultracode 可叠加；未启用时沿用现有会话行为。
- Plan 提交后使用底部批阅抽屉，内部渲染 Markdown，支持两档高度、稍后批阅、提出修改和返回原计划。
- 待批阅计划保留重新打开入口；批准后显示正文中的批准记录、运行中的执行状态及本轮收尾状态。
- Goal 的状态及预算信息分为简要入口与二级详情，完成记录绑定原轮次，不错误延续到后续普通消息。

### 上下文整理与推进清单

- 接入上游默认 CLM 自动上下文维护，桌面端同步维护状态、权威使用量，并处理失败回退、取消及恢复。
- 指令菜单提供 `/clm` 与 `/clm-compact` 入口；手动整理的原始信息收纳为可查看的引用，不把整段维护提示挤进正文。
- 推进清单采用上游独立任务记录及请求级只读快照，减少对摘要正文的依赖。补齐 CLM、原生压缩、重开和分支隔离回归，核对任务状态、负责人及阻塞关系。

### 权限与审批

- 跟进上游三档权限：询问、代为审批、完全访问；旧权限配置按当前规则迁移。
- 完全访问遵循上游风险确认及授权范围。常规操作无需逐次人工审批，但显式工具拒绝／确认规则与客户端跨会话审批仍然生效。
- 审批改为底部抽屉，可稍后处理，并从待审批入口重新打开；保留完整参数与风险说明。

### 聊天栏与引用

- 指令和附件菜单采用分组、过滤及键盘选择，保留模型与思考组件的操作层级。
- 网页链接识别后在输入文字原位显示图标和链接样式，图标可打开二级预览及内置浏览器；链接文字仍可编辑。
- 输入中的链接和命令图标仅用于显示，不改变原始发送内容及复制文本。
- 修复会话切换失败时，目标草稿预览可能覆盖原会话草稿的问题，并补充输入法、撤销／重做、粘贴和正文引用回归。

## 下载与升级

发布后下载本 Release 附件中的 **Desktop for Step Code Setup 0.4.0.exe**，并使用 `SHA256SUMS.txt` 核对安装器。

升级前结束运行中的任务，通过“文件 → 退出应用”或托盘菜单退出旧版，再运行安装器覆盖安装。仅关闭窗口不会退出应用。不要为升级删除配置目录或个人数据，重要项目与会话建议提前备份。

已有更新功能的版本可通过左下角提示及“设置 → 版本更新”发现新版；`v0.1.0` 用户需手动查看 Releases。**更新检查不会静默安装或自动重启应用。**

## 已知边界

- 本次安装包适用于 Windows x64，仍属于社区预览版。
- 客户端随固定上游源码及集成补丁构建，不在运行时自动追随上游最新提交。
- 中断后的 Ultracode 续跑需要显式恢复，不承诺自动恢复所有中断任务。并发代理不提供项目文件锁或事务隔离。
- 上下文整理的效果仍取决于模型和服务；结构化清单保留不等于任意自然语言要求都能无损保留。
- **自定义供应商继续为 Beta**，使用通用协议接入，不代表所有供应商、代理服务和模型已经验证。知名供应商专配目前优先级不高，暂无时间承诺。
- 安装器未做代码签名，Windows SmartScreen 可能提示未知发布者，请核对本仓库来源及安装器哈希。
- 本版拟继续标为 GitHub Pre-release；仅正式版更新通道不会提示该社区预览版。
