# Desktop for Step Code v0.5.0：阶跃矩阵与性能条、界面复杂度分层及六套主题，支持应用内更新

> 发布正文草稿，尚未发布；下载附件及最终版本以候选验收后的实际发布为准。

本次 Windows x64 社区预览版聚焦桌面体验：以阶跃像素矩阵呈现不同运行阶段，配合渐变总耗时与更精简的性能条；新增简洁、标准、详细三档界面复杂度与自定义，让思考和工具过程按需要呈现，并带来六套主题与自选强调色。同时加入结构化提问抽屉（Beta）、项目目录恢复与应用内下载更新。继续沿用 Step Code v0.1.4 对应的固定源码基线。

## 本次更新

### 阶跃矩阵与性能条

- 使用品牌 3×3 像素矩阵替换原脉冲点，为执行、思考、等待确认、等待响应及压缩上下文提供不同动画，状态切换采用缓动渐变。
- 运行文字与本轮总耗时共享色板流动和呼吸效果；总耗时不随阶段切换归零，与下方性能条采用同一计时口径。
- 性能条居中精简为四项：总耗时、估算输出 TPS、输入／输出 Token、缓存命中；前三项用图标，并保留悬停和键盘聚焦说明。
- TPS 根据上游输出 Token 与有效接收流时长估算，不按字符猜测；首 Token 等待、工具执行和审批等待不计入分母，缺少有效测量时显示未知。它不是服务端解码速度或整轮任务吞吐率。
- 收紧输入区底部留白，保留 Plan、Goal 与 Ultracode 的行进态和收尾入口。

### 界面复杂度与统一过程展示

- 设置新增独立的「界面复杂度」，提供简洁、标准、详细预设，也可分别自定义思考展开、工具详情、工具聚合、单行过程汇总与性能条显示。
- **简洁**：正文之间的连续思考与普通工具收纳为单行过程入口。运行时显示当前进展，结束后显示实际操作分类与数量；点击仍可查看完整记录，默认隐藏性能条。
- **标准**：思考默认折叠，相邻普通工具聚合展示，保留性能条。
- **详细**：保留独立工具行，思考仅在当前思考阶段自动展开，进入工具、正文或轮次结束后收起。工具详情仍默认折叠，自定义可开启默认展开。
- 思考行统一使用大脑图标、设计的展开箭头、耗时与状态标签，与工具行共用动态反馈和展开动画。
- 应用设置后，已有上文即时适配，不需要重新请求模型或刷新整页；原始会话记录不变。
- 审批、失败、轮次结束后仍未返回的工具及 Plan、结构化提问、Subagent、Workflow 等专用交互保持独立，不被普通过程汇总隐藏。复杂度只改变展示，不改变模型、权限或运行模式。

### 六套主题与独立强调色

- 新增六套主题：天光初霁、素笺留白、星河未眠、沧海夜航、绛夜微醺、翠林听雨；同时保留原版中性黑白与跟随系统。
- 统一正文、左栏、右栏、设置、代码块和托盘的配色，不只是更换强调色。
- 强调色支持预设、自选色盘与 HEX 输入，和主题独立保存；预览可应用或取消，重启后恢复已保存的选择。
- 主题与强调色切换使用平滑缓动，支持减少动态效果；启动首帧直接使用已保存主题。
- 正文网页链接与预览打开按钮跟随强调色；成功、失败和中断继续使用独立语义色。

### 结构化提问（Beta）

- 为上游结构化提问接入底部抽屉，支持两档高度、收起和重新打开，并通过「回答问题」状态入口继续作答。
- 支持单选、上一题／下一题，以及题目允许的自由输入；整组明确提交，提交失败可以重试。
- 收起或切换会话保留当前进程内的回答草稿；草稿不跨应用重启恢复。
- Plan 中回答问题与批准计划相互独立，不会因为提交答案就自动批准执行。

### 应用内下载更新

- Windows x64 安装版可在应用内主动下载新版，查看进度、取消或重试；下载校验完成后，仍需用户确认才重启安装。
- 安装前检查运行任务、Goal、审批、排队消息、终端等忙碌状态，并提醒未发送草稿与附件不会保留。
- 不自动下载，不在普通退出时自动安装；开发版、解压运行版或缺少所需元数据的发布继续提供手动下载入口。

### 项目管理与日常修复

- 左栏新增「移除项目」和「重新定位目录」。移除只取消登记与分组，不删除磁盘文件或会话，也不中断运行任务。
- 项目目录在应用外移动或改名后，可重新定位并恢复历史会话；保留项目名称、顺序、置顶及会话身份，不改写原始历史。
- 项目与独立会话分组折叠状态在重启后保留；优化新增按钮、排序位移与目录警告，避免遮挡恢复操作或挤动右栏。
- 修复长任务运行期间上下文用量不及时刷新的缺口，圆环与右栏继续使用同一份上游统计，不用累计输入 Token 代替当前上下文占用。
- 修复聊天栏全选后 Backspace／Delete 无法删除选区的问题。
- 支持在正文空白边界后输入 `/` 调出指令补全，仅替换当前指令片段，不自动发送；聊天输入框关闭拼写检查，减少指令和代码的红色波浪线。
- 新增透明 Logo 启动动画。
- 仓库中英文 README 新增产品展示页入口。

## 下载与升级

发布后请下载本 Release 附件中的 **Desktop.for.Step.Code.Setup.0.5.0.exe**，使用 `SHA256SUMS.txt` 核对安装器。更新所需的 `latest.yml` 将与安装器一同上传。

从 v0.4.0 升级时，请通过已有新版提示打开发布页并下载安装器；应用内下载和确认重启安装是本版新增能力，不追溯到旧客户端。

升级前结束任务，通过「文件 → 退出应用」或托盘退出旧版，再覆盖安装。仅关闭窗口不会退出应用。不要为升级删除配置目录或个人数据，重要项目与会话建议提前备份。

## 已知边界

- 安装包适用于 Windows x64，仍为社区预览版。
- 客户端使用固定上游源码及 Desktop 集成补丁，不在运行时自动追随上游最新提交。
- 结构化提问为 Beta，当前回答草稿只在进程内保留；回答问题不代替权限授权或计划批阅。
- **自定义供应商继续为 Beta**，通用协议接入不代表所有服务与模型都已验证；知名供应商专配目前优先级不高。
- 当前亮色运行态的部分浅色渐变文字不满足 4.5:1 对比度；可使用其他主题或系统强制色模式。
- 安装器未做代码签名，Windows SmartScreen 可能提示未知发布者。哈希校验用于完整性检查，不等于发布者签名或自动回滚保障。
- 计划继续标为 GitHub Pre-release；仅正式版更新通道不会提示该社区预览版。
