## 定向验收

本次不重跑整版人工云测；源码检查和同一候选的打包回归覆盖改动风险，真实账户及安装升级单独确认。

- [ ] 依赖锁一致，类型检查、完整串行单元／协议测试、生产构建通过。
- [ ] 从当前源码重新 staging 固定 runtime 并生成 D: 目录中的 NSIS x64 安装器。
- [ ] 包内版本、Desktop 与 runtime 资源、更新元数据、安装器 SHA-256 核对通过。
- [ ] 同包隔离回归：Plan 额度、API 余额、账户路由、凭据刷新与存储、更新发现及下载机制。
- [ ] 真实 Plan：套餐与额度刷新正常，发送一条消息正常。
- [ ] 真实 API：余额刷新正常，发送一条消息正常。
- [ ] 真实账户双向切换：API → Plan → API；展示及实际请求来源一致，取消登录保留原身份。余额短时间不变不作为计费来源证明。
- [ ] v0.5.0 → v0.5.1 安装升级：账户、设置与会话保留；重启后可用。
- [ ] 维护者确认最终候选；准备改动合并后冻结最终 main 提交，并从干净提交重建／复验。
- [ ] 明确授权后创建匹配的 tag 与 GitHub Pre-release，上传安装器、`latest.yml` 与 `SHA256SUMS.txt`。
- [ ] 发布后核对公开附件与更新清单，确认包含预览的通道能发现 0.5.1；生产应用内升级需实际操作，不以夹具替代。

## 验收边界

PR #129 的本地测试已经覆盖国内／海外 API 与 Plan 的请求端点和凭据配对、切换拒绝、取消授权及 Plan 拒绝后不回退 API。这些是隔离凭据与受控传输测试，不证明官方账单扣费。维护者此前确认体验正常，但不据此自动勾选本次最终安装器的真实账户或安装生命周期验收。

未发布前，v0.5.0 仍是当前公开版，不提前修改 README 的公开下载版本。
