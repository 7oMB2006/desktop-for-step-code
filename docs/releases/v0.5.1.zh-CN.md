# Desktop for Step Code v0.5.1：Step Plan 套餐额度与 API 余额查询

> 发布正文草稿，尚未发布；最终附件以实际发布为准。

本次 Windows x64 社区预览版聚焦账户用量查询：在账户设置中直接查看 Step Plan 套餐与剩余额度，或官方 API 账户可用余额，并完善账户切换后的请求路由一致性。继续沿用 v0.5.0 的 Step Code 固定源码基线，不包含上游 v0.1.5 的整体钉点升级。

## 本次更新

### Step Plan 套餐与额度

- 显示官方返回的套餐名称、可用额度、重置及到期信息，支持手动刷新。
- 按账户实际返回的额度类型与窗口展示，不固定假设所有套餐都有相同周期；未返回的额度不显示成零。
- 展示账户受限信息；临时查询失败时标注保留的旧数据，区分加载、过期与认证失效状态。

### 官方 API 账户余额

- 支持国内及海外官方 API 账户查询可用余额，并区分预付费与后付费账户。
- 余额按官方返回值展示，不把累计充值或赠送总额误当成剩余额度；接口未提供币种时不擅自标注货币符号。
- 支持手动刷新及前往官方平台查看账户详情。余额查询本身不调用模型。

### 账户切换与凭据隔离

- 登录完成后，账户查询、模型发现与会话请求按已生效的登录类型和地区同步；仅选择登录方式不代表已经切换账户。
- 运行任务期间阻止切换登录，授权未完成时阻止发送新任务；取消授权保留原账户。
- Plan 请求失败不自动回退为直调 API。凭据继续由 Desktop 独立保管，不读取个人 Step Code 配置，也不向渲染进程暴露密钥。

## 下载与升级

发布后下载本 Release 附件中的 **Desktop.for.Step.Code.Setup.0.5.1.exe**，使用 `SHA256SUMS.txt` 核对安装器；`latest.yml` 与安装器一同提供。

v0.5.0 的受支持 Windows 安装版可通过包含预览的更新通道检查并主动下载，校验后确认重启安装；也可手动覆盖安装。升级前结束任务并备份重要项目与会话，不要删除配置目录。仅关闭窗口不会退出托盘中的应用。

## 已知边界

- 适用于 Windows x64，继续作为 GitHub Pre-release 社区预览版发布；仅正式版通道不会提示此版本。
- 展示信息取决于官方接口及当前登录账户，账户余额不是单轮费用或实时扣费凭证。
- 自定义供应商继续为 Beta；本版官方余额查询不适用于第三方供应商。
- 安装器未做代码签名，Windows SmartScreen 可能提示未知发布者；哈希校验不等于发布者签名。
