# macOS 部分发布说明草稿

本页保留共享 `v0.6.0` Release 的 Mac 早期说明。两端已于 2026-10-25 联合发布，当前用户说明见 [版本正文](v0.6.0.zh-CN.md)，最终来源及验收见 [发布记录](v0.6.0-published.zh-CN.md)；下方待验收措辞保留为历史。

## macOS Apple Silicon

本版将 Windows 0.6.0 冻结线中的桌面能力整合到 Mac，并保留原生标题栏、Command 快捷键、Dock/菜单栏、zsh 终端、Keychain 凭据存储与原生文件打开方式。

- 对齐 Step Code v0.1.5 运行时及 Desktop 集成：Cron 管理与恢复 Beta、离线 Codex/Claude 会话导入、插件/MCP/Skills 管理、状态与 CLM 修订、用量统计、会话移动和搜索、自动续跑特殊状态。
- 自动续跑提示表示已发起尝试，不保证模型恢复成功。Cron 自动恢复需要单独授权；导入会话中的历史工具记录只用于展示和上下文，不执行来源工具。
- StepPage 使用 Desktop 管理的准备入口和独立存储；首次使用需完成准备。外部 MCP 服务仍需对应服务和授权。
- Mac 更新使用独立 ARM64 ZIP 与 `mac-update.json`，只接受官方 Release 中对应版本的文件，并核对大小与 SHA-512。

### 下载与安装

- 适用于 **Apple Silicon / ARM64，macOS 13.5 或以上**。当前不提供 Intel 安装包。
- 下载 `Desktop.for.Step.Code.0.6.0.arm64.zip`，解压后将 `Desktop for Step Code.app` 放入可写的 Applications 目录，再启动。
- 应用无 Developer ID 签名、未公证，系统可能要求额外的安全确认。遵循系统提示，不关闭系统安全机制。
- 旧 `v0.5.0-macos.1` 没有应用内更新功能，首次升级请手动下载。升级前退出旧版并备份应用及数据；不要同时运行两个版本操作相同数据。
- 应用数据位于 `~/Library/Application Support/Desktop for Step Code/`，与个人 Step Code CLI profile 分开。更新不应删除已有会话和设置。

### 校验与测试范围

使用 `SHA256SUMS-macos-arm64.txt` 校验 ZIP；`COMMIT-macos-arm64.txt`、`runtime-manifest-macos-arm64.json` 与 `BUILD-INFO-macos-arm64.md` 提供该包的真实源码、runtime 和验证记录。

本地 fixture 与包内验收使用隔离配置和受控服务，不等于真实付费模型、官方账单、外部 MCP、所有 macOS 版本或公网更新安装均已通过。发布前应按候选记录填入用户实际完成的验收范围，保留未验收限制。
