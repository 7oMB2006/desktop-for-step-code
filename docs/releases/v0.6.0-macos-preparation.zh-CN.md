## 候选约定

- 应用版本与计划共享 tag：`0.6.0` / `v0.6.0`。本地测试包可以保留目标版本，但每次构建记录真实 commit、SHA-256 和候选状态；已公开附件不能用同名替换。
- Mac 为 ARM64、macOS 13.5+，无 Developer ID 签名与公证。系统可能要求安装确认；不得删除 quarantine 绕过 Gatekeeper。
- 保留原 `Step-Code/` checkout。新 runtime 使用独立源码目录、v0.1.5 固定提交和受校验的补丁，不复用旧 bundle。
- 用户数据仍在 Electron userData；测试仅使用隔离 profile。不得拿日用凭据、会话或定时任务做自动测试。
- 最终本地候选必须从干净提交构建；`macos-update.json`、`COMMIT-macos-arm64.txt` 与包内 runtime 清单给出真实来源。

## Windows 与 Mac 接力

1. Windows 一方完成 Windows 准备，创建并**保存草稿**，不点发布。草稿放在 `7oMB2006/desktop-for-step-code`，共用 `v0.6.0`。
2. Mac 完成本地候选并交给用户实测；通过后向同一草稿添加 ARM64 ZIP、`mac-update.json`、`SHA256SUMS-macos-arm64.txt`、`COMMIT-macos-arm64.txt`、`runtime-manifest-macos-arm64.json` 和 `BUILD-INFO-macos-arm64.md`。
3. Windows 复查公共说明、安装包分流和版本；Mac 二审核对实际上传文件、大小/哈希、runtime、安装说明与更新清单契约。
4. tag 指向的最终源码必须包含双方发布所需改动。本次共享滚轮转发、供应商焦点样式和托盘尺寸修复也影响 Windows，Windows 应在合入最终代码后重新构建候选，不能直接沿用较早的冻结线包。`324e71d` 是功能冻结点，不是已经含有 Mac 整理修复的最终 tag；双方在发布前协调最终 commit，分别从最终提交构建或明确审核平台构建来源。
5. 双方审核与用户真实测试均无阻塞项后，再由维护者发布。不可变 Release 必须在草稿阶段传齐附件。当前目标不包含点击发布、创建 tag 或替换公开附件。
6. 发布后核对 update-feed 同时生成 Windows `channels` 与 `platforms.darwin`；仅上传附件不保证触发更新源刷新，必要时手动运行工作流。验证从公开地址下载的附件与审核哈希一致。

双方错开编辑发布说明，接手前刷新草稿。平台证据文件各有独立名称，避免覆盖 Windows 校验和。共享功能说明写一次，安装条件、已知限制及测试范围分平台列出。

Mac 共享版本的自动更新以静态 `platforms.darwin` 清单为准。Atom fallback 无附件信息，只能识别明确的 `-macos.N` tag，不能据 Windows 通用 tag 猜测 Mac 已发布。

## 用户回来后的人工测试

下列项目留给用户确认，自动化通过也不提前勾选：

- 退出旧版后，从测试 ZIP 解压并在可写 Applications 目录启动；完成 Gatekeeper 确认。先备份旧 app，升级前备份数据；不要让旧、新版同时操作日用 profile。
- 原有账户、设置、项目、历史和文件打开偏好保留；重启后仍可读取。确认 Keychain 提示和账户切换符合预期。
- 真实 Plan/API 各做一次正常对话、工具操作与审批；核对模型选择、失败显示与账单模式。付费调用仅由用户主动测试。
- 检查 Cron 创建、暂停、编辑、手动恢复及宿主会话跳转；自动恢复仅在理解授权后开启。不要用重要定时任务试验。
- 用非敏感样本预览并导入 Codex/Claude 会话，确认来源工具只显示、不执行；跨项目移动、搜索和重启回放正常。
- 试用插件/MCP/Skills、用量页面、status、CLM 修订、批注、底部终端及 diff 切换。检查 Command 快捷键、标题栏、Dock/菜单栏、窗口关闭与退出确认。
- 自动续跑发生时确认显示的是“已发起”特殊状态，不是人工用户消息；不能把它当成模型恢复成功的证明。
- 公网下载和真实应用内更新安装、旧系统执行兼容性、外部 MCP 与 StepPage 服务的可用性仍需独立证据。

本轮机器为本机 Apple Silicon；最低系统版本元数据检查不能代替在 macOS 13.5 的物理执行测试。最终自动化与构建结果写入 `docs/VERIFICATION.md` 及候选 BUILD-INFO。
