## Mac CI 根因与修复

原运行 `40101170389` 的源码阶段在“项目选择器至少五行”断言失败，后续云端包内验收被跳过。云端截图实际为 1440×684；测试虽然请求 1440×960，但 macOS 显示区域会钳制原生窗口。

在已验收的原包上限制高度为 684px，可以原样复现：菜单位于输入框上方，列表约 74px，六个项目均存在，只有约两行同时可见。正常空间下列表为 190px，可完整显示五行。原断言把正常空间前提错误地应用到受限窗口。

修复仅调整验收脚本：

- 以实际菜单、行高及可用区域判断是否足以容纳完整五行；宽裕空间保留五行断言。
- 受限窗口仍严格检查完整单行、菜单不越过输入框、可滚动全部六项、最后一项实际选择正确，且不创建 worker 或历史。
- 保留搜索、草稿、独立/项目切换、键盘、首次发送只创建一个真实会话等原有断言；路径对比按真实目录解析，兼容 macOS `/var` 与 `/private/var` 别名。
- 增加原生高度上限复现入口、几何记录及失败截图。

本机源码 1440×960 和原包 1440×684 均完整通过新建会话验收，后者使用隔离配置与本地 fixture provider。应用、样式、runtime 和已验收 ZIP 均未修改。云端结果必须以修复提交的完整源码与包配置检查为准，不能将原来被跳过的检查记为通过。
