# Desktop for Step Code v0.6.0：用量统计、插件管理与定时任务

> 发布正文草稿，尚未发布；最终范围、平台和附件以候选验收及维护者确认为准。

本次 Windows x64 社区预览版在 v0.5.1 的套餐额度与 API 余额查询之上，新增本机用量统计、官方费用估算、插件与 Skills 管理，以及定时任务管理和恢复 Beta。会话支持离线迁移、跨项目移动与搜索，右栏补齐状态和 CLM 修订查看，并优化会话切换、终端布局及任务进度反馈。Windows 运行时对齐 Step Code v0.1.5 对应的固定源码基线。

## 本次更新

### 本机用量统计与消耗估算

- 新增用量主视图，提供年度热力图、每日模型分布、24 小时用量与缓存命中率，以及近 7／30／90 天和自定义日期趋势。
- 可按全部、阶跃官方或自定义第三方来源筛选；查看区间合计和明细，并切换默认／K／M／B 数字单位。
- 上下文面板按已生效的官方账户显示 Plan M Credit 或 API 金额估算；按响应发生时的账户、地区和计费规则分组保存，切换账户不重算旧记录，也不会改变真实计费方式。
- 本机统计不等于账户云端账单；估算不包含所有调用，未知价格不当成免费。第三方仅统计 Token，不提供官方金额或 Plan Credit 换算。

### 插件、MCP 与 Skills

- 左栏新增插件入口，设置中统一管理已安装插件、发现和市场来源，支持添加本地或 Git 市场来源、安装与卸载。
- MCP 分开显示配置启停与当前会话连接状态；插件声明的资源随插件管理，不与独立配置混淆。
- Skills 支持创建、从本地文件夹导入、启停和删除；管理使用 Desktop 独立目录，不写入个人 CLI 配置。
- 配置保存不自动重启现有会话。插件所属 MCP 尚被常驻会话使用时，卸载会要求先停用并释放相关连接。
- Windows StepPage 增加显式准备、校验和重试入口，兼容旧配置迁移并保留显式禁用状态。
- 插件可通过 `step.plugin.json` 的可选本地 PNG 图标展示个性；这是 DFSC Beta 展示扩展，不是上游标准，也不代表插件认证。

### 定时任务与恢复 Beta

- 新增定时任务管理页，支持项目筛选、搜索、创建、删除、下次触发和到期信息；区分临时与持久任务、在线宿主与离线记录。
- 持久任务遵守项目信任要求；有任务的宿主不会被普通空闲回收，等待触发不等于模型正在执行。
- Desktop Beta 支持关联已有会话、核对账户／模型／Ask 后恢复项目调度，以及明确授权后的应用启动和空闲宿主异常恢复。自动恢复默认关闭，授权最长七天。
- 支持单任务暂停、恢复和编辑指令／时间；保留任务身份和原到期限制，暂停不触发，恢复不补跑。
- 提供有限执行与恢复记录、当前宿主跳转；任务到期、配置变化或执行结果未确认时阻断自动恢复，不自动换账户、补跑或重试。
- 定时触发在聊天中按轮次呈现；退出应用前使用统一确认窗口提示仍在运行的任务和调度状态。

### 上下文、状态与 CLM 修订

- 右栏新增状态页，使用 `/status` 或手动打开，查看实际模型、思考、权限、目录、账户方式及脱敏运行时诊断；默认仍打开上下文。
- 新增 CLM 页签，查看当前分支的修订、保存内容和上游记录的修改对比，支持历史浏览与回到最新。
- 修订内容以只读 Markdown 展示；修改对比提供可选择的前后片段，并保留默认折叠的原始 diff。不伪造缺失的历史内容、身份或用量。
- CLM 启停和手动整理复用原生运行时；手动整理需要确认，可能调用当前模型。查看状态和修订本身不调用模型。
- 上下文、状态、CLM 与变更面板支持标准、宽幅和全屏宽度，切换时保留面板内容与滚动。
- 补齐 `/usage`、`/status`、插件、MCP、Skills 等桌面命令入口，并统一指令图标及行内展示。

### 会话迁移、搜索与组织

- 设置中可显式扫描并批量导入本机 Codex／Claude Code 会话，支持筛选、预览、目录映射、确认和取消；导入为独立副本，不改写来源。
- 迁移保留可支持的历史内容和来源提示，不激活原有凭据、权限、审批或工具状态，也不将历史用量当成新支出。
- 已保存会话可在独立历史与项目之间移动，或跨项目移动；不移动项目文件、不继承原目录的完全访问与信任。
- 左栏搜索可匹配标题、首条消息、项目名和目录，保留排序与折叠偏好；不扫描完整聊天正文，归档会话仍由归档页搜索。
- 正文新增批注入口，与普通引用分别操作。

### 会话切换与面板体验

- 冷切换先呈现可用历史，允许复制、展开过程并立即编辑目标会话的文字草稿；等待运行时就绪期间不允许发送或执行，也不会就绪后自动发送。
- 快速连续选择以最后目标为准，草稿按会话隔离；正式接入时保留输入焦点、光标和阅读位置。Windows 按可用内存保留适量空闲运行时，减少重复启动等待。
- 终端可在右侧与底部停靠，切换保留现有终端和进程；底部高度可调整，位置与高度保存到偏好设置。
- 变更面板支持行内与左右对比，保留文件展开和复制操作；原有正文变更预览保持不变。
- 任务进度未完成时使用黄至紫流动色带，匹配本轮完成事件后播放轻震、绿色扫过和像素粒子，并与完成提示音共用触发事件。
- 旧轮次已完成清单归入上方折叠历史，未完成工作继续保留；优化展开交互、思考推条跟手、主题配色和长时任务的耗时显示。

### 上游兼容与可靠性

- Windows 运行时升级到 Step Code v0.1.5 对应源码钉点，完善 Workflow／Subagent 的停止中、部分失败、节点错误、回调错误、重试与恢复信息。
- `edit_file`／`write_file` 的 `then_run` 沿用统一命令执行和审批语义；验证命令失败不误报为文件修改失败，改进 Windows 嵌套命令停止处理。
- 保留 Plan 外部审批契约，不把计划交接或退出当成用户批准。
- 修复官方模型列表刷新竞争与模型选择持久化，避免临时不可用时静默切换到其他模型。
- 修复摘要板 Git 仓库差异的增删配色，以及正文接近底部时向上阅读仍被自动拉回的问题。
- 自动续跑使用独立时间线状态，与模型切换提示统一展示；不再冒充用户消息，也不将内部续跑指令混入复制的回复正文。提示仅表示已经发起续跑，不代表恢复成功。

## 下载与升级

发布后下载本 Release 附件中的 **Desktop.for.Step.Code.Setup.0.6.0.exe**，使用 `SHA256SUMS.txt` 核对安装器；`latest.yml` 与同一安装器一同提供。

受支持的 v0.5.x Windows 安装版可通过包含预览的更新通道主动下载，校验后确认重启安装；也可手动覆盖安装。升级前结束任务、处理临时定时任务，并备份重要项目与会话；不要先卸载或删除配置目录。仅关闭窗口不会退出托盘中的应用。

## 已知边界

- 本文先说明 Windows x64 候选的范围，继续使用 GitHub Pre-release 社区预览定位，不是 `1.0` 稳定性承诺。macOS 联合附件、平台差异和原生验收待 Mac 侧补齐并交叉复查，不能由共享源码或 CI 推定全部能力一致；Linux 不在本次范围。
- 用量仅覆盖本机可读取记录。官方账户余额、Token 统计与本地费用估算是不同口径；第三方价格配置和海外 Plan Credit 换算尚不提供。
- Cron 恢复与暂停／编辑为 Desktop Beta，不保证多宿主独占或精确一次执行；应用退出、电脑休眠后不提供常驻调度承诺。暂停的持久记录使用新 Beta 格式，旧版或 CLI 可能保留但不调度；回退前应在新版显式恢复或删除。
- 插件安装和来源管理沿用上游能力，不提供独立社区审核或安全认证；插件与 MCP 可能执行本地代码，应自行核对来源及权限。
- 会话迁移不是完整备份；不支持或缺失的附件会提示，导入历史不恢复来源运行环境。大历史和带 MCP 的冷启动仍可能需要等待，首屏可读不等于模型已就绪。
- 自定义供应商继续为 Beta，通用接入不代表所有服务、模型或工具调用均已验证。
- 部分亮色运行态渐变文字对比度偏低，可使用其他主题或系统强制色模式。
- 安装器未做代码签名，Windows SmartScreen 可能提示未知发布者；哈希校验用于完整性检查，不等于发布者签名。
- 仅正式版更新通道不会提示此社区预览版。
