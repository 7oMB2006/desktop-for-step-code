# 文本整理台

这是 DFSC **第三方投稿流程示范**，不是已经公开上架的外部作者作品。
仅用公开插件清单、文档与声明式配置，不依赖 BVR 或任何宿主专用适配。

将用户提供的多行文本去重、排序、整理成 Markdown 清单，或统计文本。
工具不联网、不调用模型、不读取用户文件，也不写入剪贴板或项目。

完整说明见 [使用指南](docs/GUIDE.md)，字段解释见 [配置说明](docs/SETTINGS.md)。
MIT 许可证；运行需要 PATH 上的 Node.js 22+ 和支持插件骨架协议的 DFSC。
目前只在骨架开发构建上验收，不能据此声称已发布的 0.6.0 均支持它。
