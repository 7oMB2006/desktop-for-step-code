# 文本整理台

**第三方投稿流程示范 · 0.1.0**

整理粘贴的文本，不需要 Key，也没有需要下载安装的外部服务。
这是 DFSC 项目提供的流程示范，尚未公开上架，不冒充外部贡献者。

## 可以做什么

| 工具 | 作用 |
| --- | --- |
| `prepare_list` | 去掉空行与首尾空白，按设置去重、排序，输出清单 |
| `analyze_text` | 返回字符、行数、非空行、唯一行和重复行统计 |
| `/tidy-text` | 把指令后的内容交给清单工具，不另造一种处理逻辑 |

不自动读取文件、修改项目、写剪贴板或创建任务。
输出的待办框只是 Markdown 文本，不会变成 DFSC 的任务清单。

## 第一次使用

1. 安装插件，打开卡片上的齿轮。
2. 选择清单格式、去重与排序方式，点击「保存配置」。
3. 点击「重启当前会话」，在「能力」确认服务连接。
4. 在会话中输入下面的指令，或明确要求使用文本整理台。

```text
/tidy-text
核对配置
补充测试
核对配置
更新文档
```

默认设置得到：

```markdown
## 整理结果

- 核对配置
- 补充测试
- 更新文档
```

## 设置如何生效

在[配置说明](SETTINGS.md)查看每个字段。
保存不会自动中断会话；修改配置后需明确重启。
旧进程发现配置变化会拒绝继续处理，不会假装已经应用。
最多处理 16,000 个 UTF-16 单元，超长输入明确报错，不静默截断原文。

重复行按去掉首尾空白后的原文精确比较，区分大小写。
字符顺序不是拼音顺序或自然数字顺序。
统计中的字符数是 Unicode 码点数，不是视觉字形数。
换行也计入字符数；空字符串为 0 行，末尾换行会增加一个空行。

## 费用和权限

这两个 MCP 工具离线运行，不调用模型、账户桥或付费 API。
但是会话和 `/tidy-text` 指令仍经过当前聊天模型，正常产生其模型用量；
不要把“工具免费”理解为“整轮对话免费”。

安装本身不安装 Node.js。需要本机 PATH 上已有 Node.js 22+。
服务仅校验自己的安装记录并读取宿主提供的插件配置，不读取个人
Step Code 配置或用户提供的路径。它不需要保存秘密。

关闭卡片开关只停用该插件的 MCP 服务，现有会话需重启后应用；
技能和提示命令仍可能显示。完整移除请卸载插件。
卸载会撤销配置绑定，宿主可能保留私有历史配置，不等于彻底擦除。
重装后不会自动接管旧实例的配置。
