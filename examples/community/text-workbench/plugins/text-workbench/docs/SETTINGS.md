# 配置说明

| 字段 | 默认值 | 对实际功能的影响 |
| --- | --- | --- |
| 清单标题 | 整理结果 | 清单前添加二级标题；留空不加 |
| 清单格式 | 项目符号 | 可改成编号清单或 `- [ ]` 待办文本 |
| 最多输出条数 | 50 | 1 至 200 的整数；省略条数会写在结果末尾 |
| 合并重复行 | 开 | 去掉首尾空白后精确去重，保留第一次出现 |
| 排列顺序 | 保持原顺序 | 可按 UTF-16 字符顺序升序或降序排列 |

处理顺序为：分行、去掉首尾空白、移除空行、可选去重、可选排序、条数限制。
不会去掉原有编号或清单标记，也不会改写正文内容。
`analyze_text` 不受上述设置影响，但同样校验配置绑定与重启状态。

例如输入 `beta`、`alpha`、`beta`，设置标题为空、编号、去重开启、
字符升序、最多 1 条，输出为：

```text
1. alpha

另有 1 条未展示（受最多输出条数限制）。
```

保存后明确重启当前会话。配置发生变化或被卸载后，旧进程拒绝新调用。
这里没有 Key、模型来源、ASR 或目录字段，因为本插件不使用这些能力。
