## 安装后得到什么

- 一个本地 stdio MCP，提供 `prepare_list` 和 `analyze_text` 两个工具。
- `/tidy-text` 提示命令与 `text-workbench` 技能。
- 标准使用说明、配置、能力和更新记录，不需要宿主专用适配。

配置能实际影响标题、列表格式、最大条数、去重和排序。
工具不联网、不调用模型、不读写用户文件。
会话和提示命令仍使用当前聊天模型，可能产生正常用量。

## 兼容与依赖

需要 PATH 上的 Node.js 22+，不自动下载或安装依赖。
需要包含 2026-11-04 插件骨架协议的 DFSC 构建；
不能把已发布的 0.6.0 一概视为支持该开发协议。
在配置页面保存后明确重启会话，查看实际 MCP 连接状态。

停用开关仅控制 MCP，旧会话重启后应用；技能和命令不是服务开关的一部分。
完整删除用卸载。历史私有配置由宿主保留并撤销绑定，重装使用新实例。
