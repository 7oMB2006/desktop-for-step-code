# Troubleshooting

## No Titlebar Entry

The host may not include the optional plugin-workspace feature.
The same application version number can identify builds with different source
features. Confirm that your build includes plugin workspaces, then verify the
plugin is actually installed rather than only listed in Discover.

Unknown or conflicting installation provenance, an invalid desktop declaration
or a missing packaged Markdown page prevents the entry from appearing.
Review the plugin's warnings in Plugins. Do not bypass this by editing private
installation receipts or copying files into the application's profile.

## The Command Is Missing

An existing conversation must explicitly reload the installed resources.
Wait for running work to finish, then use the host's restart action.
Confirm that DFSC Example remains installed and the correct conversation is open.
Opening these pages alone does not reload a conversation.

## No Response

Check the conversation's actual account, model and error state.
Resource installation does not establish account validity, available quota,
network access or a successful model call. This package has no independent
provider settings.

## Update or Remove

Use the host's plugin update or uninstall operation.
An old open workspace reference becomes invalid when its package changes.
Return to the current plugin entry instead of repeatedly using the old page.
Removing this resource does not stop existing work or revoke unrelated account
permissions. Reload affected conversations when appropriate.
