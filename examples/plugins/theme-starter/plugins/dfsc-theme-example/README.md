# Theme Composition Example

这是宿主维护的 v2 主题示例，不是已经上架的第三方作品。
需要包含主题组合协议的 DFSC 构建；相同的 `0.6.0` 版本号不能证明具备该能力。
`requirements.dfsc` 故意未填，发布前须换成自己实际验证的范围。

## 安装与启用

在「插件 → 市场来源」添加本示例 `theme-starter` 市场根目录的绝对路径，
在「发现」安装 `dfsc-theme-example`，再到「外观 → 主题包」选择
Theme Composition Example。安装本身不会切换主题。

默认显示包内原创几何图片，界面采用宿主标准皮肤。
如使用包含自定义背景宿主适配的构建并另行安装该插件，导入并启用本机图片后，
只替换底图，主题色和 UI 保留；选择「跟随主题」恢复包内底图。
示例不自带该插件，也不因声明 `accepts` 自动取得背景编辑器。
该适配当前由宿主候选 PR #223 提供；仅含组合协议的主线构建可以使用本包的
默认图片与主题色，但不代表已经包含个人图片导入或编辑入口。

## 范围与恢复

本包不包含 MCP、技能、命令、账户、网络请求、安装脚本或第三方前端代码。
底图与图标由示例的 `generate-assets.mjs` 确定性生成，随包 MIT 授权，
没有使用星辰巡航或用户上传的图片。

选择内置主题可停用本主题；卸载当前主题后宿主回退默认主题。
旧客户端可能显示“已安装”却不在外观中列出，应先核对构建能力，
不要通过添加 HTML、CSS 或 JavaScript 入口尝试绕过。

包内 PNG 供实际导入与显示测试，静态校验通过不等于客户端或平台已验收。
首次使用、原图/替换/恢复、卸载和可读性须在自己的目标构建上分别检查。
