# 自定义背景

在兼容主题中使用自己的本机图片，不更改当前主题的配色和控件样式。
此插件需要提供 `custom-background-v1` 宿主适配器的 DFSC 客户端。
普通 Step Code 插件市场能够安装文件，不代表客户端能够启用该背景。

## 使用

安装后，在插件详情的配置页选择一张 PNG 或 JPEG 图片，再启用背景。
可调整适应方式、位置、缩放、亮度、模糊与鼠标视差。设置由宿主保存，
不需要模型或 MCP 服务，也不需要重启会话。

内置主题允许使用自定义背景。主题包必须明确开放 `image-v1` 背景插槽；
未开放的主题保持原来的完整外观。切到不兼容主题时，图片与参数保留但不生效，
切回兼容主题后恢复。原版星辰巡航未开放替换底图，不会同时运行两套背景。

关闭背景和卸载插件都会停止生效；个人导入的图片和参数保留在 Desktop 的
私有用户数据中，不会写入项目或插件包。重新安装后需再次启用。
删除图片是单独的明确操作，不会删除最初导入的源文件。

## 范围

第一版仅支持单张 PNG 或 JPEG 静态图片。不支持 WebP、GIF、视频、HTML、
远程图片地址或任意 CSS、JavaScript。导入的图片由宿主校验并转存，
插件本身没有文件系统、网络、Node.js 或任意 IPC 权限。

模糊只作用于背景图，不会把整个界面的文字和控件一起模糊。
鼠标视差遵循系统减少动态效果设置，并在界面不可见时停止。
图片调节不能保证任意主题组合都美观；主题作者仍然拥有背景兼容性决定权。

## 宿主声明

`dfsc.appearance.json` 仅声明已知的宿主适配器：

```json
{
  "schemaVersion": 1,
  "provider": "custom-background-v1"
}
```

这不是可执行前端插件协议。宿主只接受有记录、未被修改且身份明确的安装，
并要求插件显式声明空的技能、指令和 Agent 列表，且不能声明 MCP 服务或其他可执行能力。
安装或卸载仍遵守普通插件管理的运行时空闲检查。

插件图标使用 Lucide 的 `Wallpaper` 图形，许可见 `ICON-LICENSE.txt`。
