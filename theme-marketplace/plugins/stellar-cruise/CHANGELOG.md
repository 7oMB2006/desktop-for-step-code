# 更新记录

## 0.2.0

- 补全作者、包内说明、更新记录和展示页入口，封面使用包内图片。
- 声明面向 DFSC 1.x，最低正式版 1.0.0，无额外运行依赖；原版支持主题背景、亮度与动态选项。
- 配套宿主更新：新增「推进清单星图」开关，默认开启；关闭后保留任务列表、状态和进度，不影响背景。
- 配套宿主更新：托盘使用宿主已解析的完整主题色，不再回退为默认黑色。
- 托盘加入金青细碎星尘与轻微明灭的星点，遵循动态开关和系统减少动态设置。
- 配套宿主更新：启动徽标以星辰非线性聚拢，首帧不闪回普通徽标；
  慢启动和故障提示渐显，徽标位置固定，重试沿用安全关闭流程。
- 配套宿主更新：插件独立窗口跟随主题切换；MiniChat、插件工作区、
  市场要求提示、Remote 与全局指令延续石墨阅读材质。
- 修正模型列表、收藏列与翻面泄露；强度推子保留原色卡，加入宽星尘、
  明亮短拖尾与最高档流动，并保留原尺寸、键盘操作和减少动态行为。
- 补回正文底部渐隐，引用、行进 Diff、排队和回底操作行不被遮罩淡化。
- 对齐新的背景组合宿主，保留一体化星海与自有阅读材质，不强制开放个人图片。

这些界面能力由宿主提供；仅升级数据包不能替代宿主更新。
