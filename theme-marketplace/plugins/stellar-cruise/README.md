# 星辰巡航

![星辰巡航](cover.png)

双龙星海动态场景，搭配石墨阅读面板、铅笔细线与星辰徽标。

## 使用

在插件市场安装并启用后，进入「设置 → 外观」选择「星辰巡航」。
主题包不会自动改动当前外观。切回任一内置主题即可退出。

外观设置可调整场景亮度和动态效果。系统启用「减少动态」时，
聚拢与循环运动停止；不能使用 WebGL 时显示静态后备素材。

## 客户端要求

主题包版本是 **0.2.0**，面向 **DFSC 1.x**。最低正式版是 **DFSC 1.0.0**；
公开旧版 v0.6.0 早于主题支持。

| 客户端 | 安装本包后可用 |
| --- | --- |
| 原版 DFSC 1.0.0 | 双龙星海、石墨阅读材质、动态背景和亮度设置；摘要里的任务星图始终随短清单显示。 |
| 包含配套宿主更新的构建 | 在上述基础上新增「外观 → 星辰巡航 → 推进清单星图」（默认开启）。关闭只隐藏星图，保留清单和进度条。另含托盘、启动徽标及插件独立窗口等增强。 |

两个构建使用同一份数据包和 `stellar-v1` 渲染器。仅更新插件不会升级客户端，
也不会给原版 1.0.0 补装这些宿主功能。

本主题声明无需额外运行环境、账户、MCP 服务或模型调用。
需要的渲染代码随 DFSC 提供；包内只有受控的清单、场景数据与图片。

## 背景组合

本版保留 schema 1 的一体化星辰设计，使用星辰 UI 与默认双龙星海，
不开放个人图片替换。新的组合协议仍兼容此模式，不需要为了上架强拆背景。
已保存的个人图片与参数会保留，切换到支持替换的主题后仍可使用。

星辰阅读面、输入框与侧栏使用主题自己的材质，不跟随自定义背景插件的
分区透明度设置改变。仅背景渲染器负责创建和释放场景，不叠加第二套背景。

## 覆盖范围

- 欢迎页、会话、侧栏、工具记录、审批抽屉和设置。
- MiniChat、会话选择器、插件工作区、侧面板与独立窗口。
- 托盘菜单、启动徽标、市场要求与更新提示、Remote 和全局指令编辑。
- 模型列表与翻面、原色卡星尘强度推子，以及正文与输入操作栏之间的渐隐。

沿用宿主的尺寸、快捷操作和窗口行为，不常驻原本按需出现的状态控件。
在线、失败、审批等状态颜色仍表达实际状态。
